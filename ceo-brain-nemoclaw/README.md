# NemoClaw Workspace: CEO Brain

Copy this workspace into the NemoClaw/OpenClaw sandbox. Set
`CEO_BRAIN_API_URL` to the operator-approved host route for the GB10 API, then
use `tools/ceo_brain_tools.py` as the only project-evidence tool.

The API route must be allow-listed in OpenShell policy. The workspace does not
contain MongoDB credentials, GitHub write credentials, or `ground_truth.json`.
